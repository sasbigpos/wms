Firebase Setup: What You Need To Do

Follow these 5 simple steps to connect your warehouse to Firebase. The whole process takes about 5 minutes.

📌 STEP 1: Create a Firebase Project

1. Go to https://console.firebase.google.com/
2. Click "Create a project" or "Add project"
3. Name your project: warehouse-wms (or any name)
4. Turn OFF Google Analytics (click the toggle to disable)
5. Click "Create project" → Wait 10-20 seconds

✅ After creation, you'll see "Your new project is ready"

🌐 STEP 2: Register Your Web Application

1. On the project dashboard, click the "</>" (Web) icon to add a web app
2. App nickname: wms-app
3. Click "Register app"
4. IMPORTANT: You will see a configuration object. COPY THIS ENTIRE OBJECT - it looks like:

{ apiKey: "AIzaSyD3W-j1l1gDH4m0RPHRnImQZjWvEA-XjMs", authDomain: "warehouse-ccc23.firebaseapp.com", projectId: "warehouse-ccc23", storageBucket: "warehouse-ccc23.firebasestorage.app", messagingSenderId: "946331303130", appId: "1:946331303130:web:7bbddb616567a11eb079e3" }

5. Click "Continue to console" (you don't need to install SDK)

🗄️ STEP 3: Create Firestore Database

1. In left sidebar, click "Firestore Database"
2. Click "Create database"
3. ⚠️ IMPORTANT: Choose "Start in test mode" (this allows read/write access for development)
4. Select a location close to you (e.g., eur3 (Europe) or nam5 (US))
5. Click "Enable" → Wait for database creation

✅ Your Firestore database is now ready! It will appear empty initially.

🔧 STEP 4: Paste Your Firebase Config Below

Paste the configuration object you copied from Step 2 into the box below. Then click "Connect to Firebase".

const firebaseConfig = { apiKey: "YOUR_API_KEY_HERE", authDomain: "YOUR_AUTH_DOMAIN", projectId: "YOUR_PROJECT_ID", storageBucket: "YOUR_STORAGE_BUCKET", messagingSenderId: "YOUR_SENDER_ID", appId: "YOUR_APP_ID" };

🚀 STEP 5: (Optional) Set Up Security Rules

For production, update Firestore Rules to secure your data. Go to Firestore → Rules and paste:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /products/{document} {
      allow read, write: if true;
    }
  }
}
For production, add authentication rules. Test mode is fine for learning.
After connecting: The Inventory tab will automatically load your Firestore data. Add products and they'll sync to the cloud!
